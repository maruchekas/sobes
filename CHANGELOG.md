# Changelog

## v0.1.0 — первый MVP (2026-10-03)

Полный цикл подготовки к собеседованиям: каталог, вход, практика с интервальными повторениями, дашборд и Telegram-бот.

### Каталог и SEO
- Банк из 112 вопросов по Java/Kotlin/Spring/микросервисам с фильтрами по теме и уровню (`83fdb63`, `92a26a5`)
- Каталог на Next.js с серверным рендерингом (`852d339`)
- sitemap.xml (137 url), robots.txt, canonical + OpenGraph + JSON-LD QAPage (#4)

### Аккаунт
- Вход через Telegram Login Widget с JWT-сессиями (`5d8ff6d`)
- Личный кабинет: таймзона, время напоминаний, флаг подписки (`4d0cdc6`)
- Исправления надёжности логина: 400 на подделку подписи (`577f486`), username при первой регистрации (`71a0ce8`)

### Практика (SM-2)
- Интервальные повторения: due-очередь, самооценка AGAIN/HARD/GOOD/EASY (`d27755c`)

### Дашборд
- Прогресс по темам, слабые темы, серия дней, готовность к собеседованию (#1)

### Telegram-бот (@sobes_auth_bot)
- Скелет: long polling на чистом JDK, привязка аккаунта одноразовой ссылкой (#3)
- Вопрос дня: ровно один в локальные сутки юзера, по времени из кабинета (#5)
- Напоминания о просроченных повторениях, антиспам 1/24ч (#6)
- Практика прямо в чате: inline-кнопки самооценки, единая SM-2 очередь с вебом (#10)
- /stats: прогресс и слабые темы, цифры согласованы с дашбордом (#11)

### Инфраструктура
- CI: сборка + интеграционные тесты на живом PostgreSQL (Testcontainers), публичные аннотации падений (`6a66f7a`)
- Git-флоу: feature → PR → squash-merge в develop; branch protection rulesets
- Модуль `bot/` — отдельное Kotlin-приложение без внешних зависимостей
