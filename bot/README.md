# Telegram-бот Sobes

Модуль ежедневной практики: вопрос дня, напоминания по расписанию повторений, короткие отчёты о прогрессе.

Планируемый стек: Kotlin + Telegram Bot API, обращается к бэкенду по REST (`/api/v1`), своей базы не имеет.

Статус: в разработке на неделе 5 роадмапа (см. [README](../README.md)).
